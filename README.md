# AgroPro-

AGROPRO es una plataforma operacional agropecuaria mobile-first orientada a conectar planificación, ejecución, evidencia, conciliación y resultado.

## Documentación

- [Domain Blueprint v0.2](docs/DOMAIN-BLUEPRINT-v0.2.md) — límites de dominio, plataforma compartida, agricultura, contratistas, cosecha, logística, ganadería, feedlot, tambo, mantenimiento y soporte de campaña.

## Estado

El producto se encuentra en redefinición de dominio antes de continuar la expansión técnica. La implementación existente en `index.html` se conserva como prototipo funcional de referencia.
