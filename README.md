# AgroPro-

AGROPRO es una plataforma operacional agropecuaria mobile-first orientada a conectar planificación, ejecución, evidencia, conciliación y resultado.

## Documentación

1. [Project Context](docs/PROJECT-CONTEXT.md) — contexto maestro para retomar el proyecto desde cualquier chat o herramienta.
2. [Domain Blueprint v0.2](docs/DOMAIN-BLUEPRINT-v0.2.md) — límites de dominio, plataforma compartida, agricultura, contratistas, cosecha, logística, ganadería, feedlot, tambo, mantenimiento y soporte de campaña.
3. [Research Synthesis — 2026-09-24](docs/RESEARCH-SYNTHESIS-2026-09-24.md) — hallazgos convergentes, riesgos y decisiones todavía abiertas.

## Estado

El producto se encuentra en redefinición de dominio antes de continuar la expansión técnica. La implementación existente en `index.html` se conserva como prototipo funcional de referencia y no define la arquitectura objetivo.
